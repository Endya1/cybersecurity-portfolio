# Security Policy Project

## Objective
This project demonstrates foundational Governance, Risk, and Compliance (GRC) skills through the creation of organizational security policies aligned with cybersecurity best practices.

## Skills Demonstrated
- Security policy writing
- Governance documentation
- Compliance awareness
- Risk reduction strategies
- Professional cybersecurity communication

## Policies Included
- Acceptable Use Policy
- Password Policy
- MFA Policy

## Framework References
- NIST Cybersecurity Framework
- CIS Controls
- ISO 27001
