# Password Policy

## Purpose
To establish password security requirements for protecting organizational systems and accounts.

## Requirements
- Minimum length: 12 characters
- Passwords must contain:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
- Password reuse is prohibited
- MFA is required when available

## Security Best Practices
- Password managers are recommended
- Passwords must not be shared
- Default passwords must be changed immediately
