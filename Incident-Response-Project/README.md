# Incident Response Documentation Project

## Objective
This project demonstrates foundational cybersecurity incident response and Governance, Risk, and Compliance (GRC) documentation skills through the analysis and reporting of a simulated phishing incident.

## Skills Demonstrated
- Incident documentation
- Security analysis
- Risk awareness
- Incident response procedures
- Professional reporting

## Scenario
This project simulates a phishing-related security incident affecting an employee workstation and email account.
