# Incident Report

## Incident Summary
An employee received a phishing email disguised as a password reset notification. The employee clicked the malicious link and entered login credentials into a fraudulent website.

## Incident Type
Phishing Attack / Credential Theft

## Affected Systems
- Employee email account
- Employee workstation

## Impact
- Potential unauthorized account access
- Exposure of employee credentials
- Increased organizational security risk

## Response Actions
- Password reset initiated immediately
- Multi-factor authentication enabled
- Suspicious email removed from inboxes
- Security team notified

## Recommendations
- Conduct phishing awareness training
- Enforce MFA across all accounts
- Improve email filtering protections
- Encourage prompt incident reporting
