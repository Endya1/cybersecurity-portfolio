# IAM Access Review Project

## Objective
This project demonstrates foundational Identity and Access Management (IAM) and Governance, Risk, and Compliance (GRC) skills through the review of employee account permissions and access control risks.

## Skills Demonstrated
- Access review analysis
- Least privilege evaluation
- Account risk identification
- Security documentation
- Governance and compliance awareness

## Scenario
This project simulates an organizational access review to identify excessive permissions, inactive accounts, and access control weaknesses.

## Framework References
- Principle of Least Privilege
- NIST Cybersecurity Framework (CSF)
- Identity and Access Management (IAM) Best Practices
