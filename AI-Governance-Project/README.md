# AI Governance & Risk Management Project

## Objective
This project demonstrates foundational AI governance, risk management, and cybersecurity compliance awareness using the NIST AI Risk Management Framework (AI RMF).

## Skills Demonstrated
- AI risk identification
- Governance and compliance documentation
- Bias and fairness analysis
- Privacy and security risk awareness
- Structured risk reporting

## Framework Used
- NIST AI Risk Management Framework (AI RMF)

## Scenario
This project evaluates potential risks associated with a hypothetical AI system used in a business environment for automated decision-making (e.g., hiring, customer service, or fraud detection).
